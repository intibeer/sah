# SAH project instructions

Read `sah-codex-handoff/AGENTS.md` and `sah-codex-handoff/PROJECT_BRIEF.md` in full before making architectural decisions. They remain the original project instructions and context. Treat proposals as hypotheses.

Current implementation and limits are documented in README.md and docs/. Run `npm run check` for policy tests, strict typechecking and compiler lint checks. Keep the prototype local and mock-only. Do not connect stores, use paid APIs, deploy, publish or choose a restrictive license without explicit founder approval. The founder selected Apache-2.0, self-hostable V1 plus pilot, and Cloudflare hosting on 2026-10-27. See docs/decisions.md for current decisions and pending external gates.
